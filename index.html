📘 Cola rápida

As tags e propriedades mais usadas na oficina.

HTML: a estrutura (o esqueleto da página)

<h1> … <h6>
Títulos, do maior ao menor
<p>
Parágrafo de texto
<strong> <em>
Negrito e itálico
<ul> <ol> <li>
Listas e seus itens
<a href="…">
Link para outra página
<img src="…" alt="…">
Imagem (alt descreve a imagem)
<div> <section>
Caixas para agrupar conteúdo
<header> <footer>
Topo e rodapé da página
class="nome"
Dá um nome para estilizar no CSS
<!-- … -->
Comentário (não aparece na tela)

CSS: o visual (a roupa da página)

color
Cor do texto: color: tomato;
background-color
Cor de fundo
font-size
Tamanho da letra: 20px
font-family
Tipo de letra: Arial, sans-serif
text-align
left, center, right
padding
Espaço por dentro da caixa
margin
Espaço por fora da caixa
border
Borda: 3px solid black
border-radius
Cantos arredondados
display: flex
Coloca os itens lado a lado
gap
Espaço entre os itens do flex
.nome { }
Estiliza quem tem class="nome"

Cores que o navegador já conhece
